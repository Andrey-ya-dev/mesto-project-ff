# Проектная работа Mesto

### [Ссылка на gh-page проекта](https://andrey-ya-dev.github.io/mesto-project-ff/)

## Описание проекта

**Mesto** — интерактивная страница, куда можно добавлять фотографии, удалять их и ставить лайки. Редактировать профиль.

## Технологический стек

- **Webpack** — модульный сборщик (bundler). Сердце сборки проекта. Он:
  - Объединяет все JavaScript-модули, CSS, изображения и шрифты в оптимальные бандлы.
  - Управляет процессом разработки (горячая перезагрузка, dev-сервер).
  - Оптимизирует финальную сборку (минификация, tree shaking, code splitting).
- **JavaScript (ES6+)** — основной язык программирования.
- **PostCSS** — инструмент для трансформации CSS с помощью JavaScript-плагинов. В данном проекте PostCSS расширяет возможности обычного CSS, позволяя:
  - Использовать современный синтаксис (переменные, вложенность), который будет приведен к совместимому со старыми браузерами виду (via postcss-preset-env).
  - Автоматически добавлять вендорные префиксы (via autoprefixer).
  - Оптимизировать финальный CSS-код (сжатие, удаление неиспользуемых правил).

## Установка и запуск

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/Andrey-ya-dev/mesto-project-ff
   cd mesto-project-ff
   ```

2. **Установите зависимости:**

   ```bash
   npm install
   ```

3. **Запустите проект в режиме разработки:**

   ```bash
   npm run dev
   ```

   Проект откроется в браузере по адресу: `http://localhost:8080`.

4. **Сборка для продакшена:**

   ```bash
   npm run build
   ```

   Собранные файлы будут помещены в директорию `dist/`.

## Полезные команды

- `npm run dev` — запуск в режиме разработки.
- `npm run build` — сборка для продакшена.
